# Fatma Yousuf | AI Engineer & Data Scientist Portfolio

Static portfolio site (no build step). Open `index.html` or host it on GitHub Pages.

## Structure
```
index.html                         main page
.nojekyll                          tells GitHub Pages to serve files as-is
assets/Fatma_Yousuf_CV.pdf         CV (Download CV buttons)
assets/Emoji_Sentiment_Infographic.pdf   infographic (Download infographic button)
assets/img/                        portrait, logos, CV pages, certificates
```

## Publish on GitHub Pages
1. Create a public repository (for a main site, name it `fatma-yousuf.github.io`, or any name such as `portfolio`).
2. Upload the contents of this folder so `index.html` is at the repository root (keep the `assets` folder).
3. Go to Settings > Pages > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, then Save.
4. After 1 to 2 minutes the site opens at `https://<username>.github.io/<repository>/`.

Keep file names and folder names exactly as they are (GitHub is case-sensitive).
